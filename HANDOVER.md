## Goal
A Linux tool (`gopt`) that tunes a Steam game's settings to an fps goal by editing config files and Steam launch options, measuring MangoHud frame logs and searching with few play runs. Dry run by default, backups, one undo per run, no sudo.

## Current state
- `gopt/parsers/keyvalues.py`, `gopt/parsers/eecfg.py`: lossless, minimal edits, round trip tests.
- `gopt/safety.py`: RunDir with MANIFEST.json, write_file (backup, atomic write, sha verify, census, shrink guard), undo once, stale plan check.
- `gopt/steam.py`: root, libraries, app manifests, user id, compatdata, launch options read and rewrite text, process checks.
- `gopt/hwprobe.py`: cpu, memory, nvidia-smi, kscreen-doctor parsing, fingerprint cache.
- `gopt/mangohud.py`, `gopt/metrics.py`: config text, log discovery, CSV parsing, metrics and pass criteria.
- Fixtures: `tests/fixtures/` (EE.cfg modelled on the documented shape, cs2_video.txt key set from a real file, localconfig.vdf, loginusers.vdf, libraryfolders.vdf, appmanifests, five MangoHud CSVs generated by `make_logs.py`).
